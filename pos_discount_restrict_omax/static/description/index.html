POS Discount Restrict

Overview

The POS Discount Restrict module is designed for the Odoo Point of Sale (POS) system to help businesses control and manage discount permissions effectively. This module integrates the HR Employee and Point of Sale modules to enforce discount restrictions at the employee level. A dedicated Discount Approval field is added to the employee form view settings, and the employee’s PIN code is also available in the HR Employee settings.

In the POS configuration settings, you can define a maximum discount limit per order line. If a cashier attempts to apply a discount higher than the configured limit, the system will display a popup and requesting the employee’s PIN. Additionally, an access control Boolean field is available in the employee settings — when enabled, it allows that employee to apply any discount amount without restriction using their PIN. This ensures that only authorized personnel can override discount limits, thereby enhancing security, accountability, and operational control within the POS environment.

Features

* Integrates HR Employee and Point of Sale modules for discount control.

* Dedicated Discount Approval field to the employee form view.

* Allows setting a maximum discount limit per order line in POS configuration.

* Displays a popup to requesting the employee’s PIN if the discount exceeds the limit.

* Provides an access control Boolean field to allow specific employees to override discount limits.

* Enhances security, accountability, and operational control in the POS environment.

How It Works

Employee
→Navigate to the Employees menu and select the desired employee to whom you want to grant access.
→Click on the employee record to open the Employee Form view.
Path → Employees


Employee Form
→Once in the Employee Form view, navigate to the Settings tab to access the configuration options for the employee.
→Locate the Discount Approval field, followed by the PIN Code field.
→Enable the Discount Approval option to allow the selected employee to authorize discounts.
→Set a secure PIN code for the employee to ensure they can approve discounts for every applicable order.


Configuration
→ Go to the Settings menu and select the Point of Sale configuration option.
→ Scroll down to locate the "Order Line Discount Fields" section.
→ Enable the Discount Limit option to set a specific discount percentage (%).
→ The discount limit field is only visible when the boolean field Allow Discount Limit is enabled.
→ Enable the field to allow employees to override the discount limit, or disable it to prevent employees from overriding the limit.
Path → Settings → Point of Sale


Product Screen
→ Go to the Point of Sale and open any session.
→ Click on any product to select it.
→ The selected product will appear on the left side of the screen.
→ Select the discount option to apply a discount to the product.
→ Your entered discount will be visible on the order line.


Discount PopUp
→ If the selected discount is greater than the limit set in the configuration, the discount popup will appear for employee authorization.
→ The employee must enter their PIN. If the PIN matches and the employee has discount approval access, only then can they apply a discount higher than the configured limit.


Access Error
→ If the employee does not have a PIN or does not have discount approval access, the popup will close and a warning message will be displayed.


Pin and Access
→ If the employee has a PIN and discount approval access, they can apply a discount higher than the configured limit.
→ If two employees share the same PIN but only one has discount approval access, the discount will be approved under the employee who has access.
→ For example, consider two employees with the same PIN: Abigail Peterson and John Doe. Only Abigail Peterson has discount approval access, so the discount will be approved under her name.


Order Recipt
→ The applied discount will be shown on the order receipt.
