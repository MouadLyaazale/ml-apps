🛡️ POS Pro Suite

Discount · Stock · Delivery · Payments

The all-in-one Odoo POS operations toolkit: PIN-protected discount limits, minimum price guard, live stock badges on product cards, receipt blocked until delivery validated, A4 delivery slip printing, and posted-order payment editing.

Point of Sale Odoo 19 OPL-1 Community & Enterprise

Overview

POS Pro Suite tackles the six most common real-world POS pain-points in a single install. Every feature is opt-in — enable only what you need via POS Settings so the interface stays clean for your cashiers and managers.

Features

🔒

Discount Limit + PIN Approval

Set a maximum discount % per order line. A popup requests a manager PIN before any higher discount is accepted.

💲

Minimum Price Guard

Block payment when the effective price after discount drops below a configured floor. PIN override required.

📦

Live Stock Badge on Product Cards

Free-to-sell qty shown on every product card in real time. Red = 0, Orange = 1–5, Green > 5.

🚚

Receipt Blocked Until Delivery Validated

Receipt screen and invoice generation are locked until the linked stock transfer is fully validated — no more forgotten deliveries.

🖨

Print A4 Delivery Slip from POS

One-click button on the receipt screen opens a DOCX/PDF delivery note in a new tab using your configured template.

✏

Post-Order Payment Editor

A backend wizard lets managers correct or reassign payment lines on already-posted POS orders without cancelling the session.

How It Works

1
Configure the employee Employees → [Employee] → Settings. Enable Discount Approval and set a PIN code. Only employees with both fields configured can authorise overrides.
2
Set POS limits Point of Sale → Configuration → Settings → Order Line Discount. Enable the discount limit and enter the maximum % a cashier may apply freely.
3
Cashier applies a discount When the entered discount exceeds the limit, a PIN popup appears automatically on screen.
4
Manager enters PIN If the PIN matches an employee with Discount Approval, the discount is applied and logged under their name. Otherwise a warning is shown.
5
Receipt & delivery After payment, the receipt screen stays accessible only once the delivery is validated. Print the A4 slip with one tap.

Configuration Reference

Employee Form → Settings tab

  • Discount Approval — grant override rights to this employee.
  • PIN Code — 4-digit PIN used in the POS popup.

POS Settings → Order Line Discount

  • Allow Discount Limit — master toggle for the discount ceiling feature.
  • Max Discount (%) — ceiling cashiers can freely apply.
  • Allow Employees to Override — when disabled, nobody can bypass even with a PIN.

POS Settings → Minimum Price

  • Enable Minimum Price Guard — blocks payment if price drops below the floor.
  • Minimum Price (%) — floor expressed as % of the original sale price.
