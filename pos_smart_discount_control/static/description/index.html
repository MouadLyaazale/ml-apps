Overview

POS Pro Suite is the all-in-one operations module for Odoo Point of Sale. It tackles the six most common real-world POS pain-points in a single install: enforcing discount ceilings, protecting your margin with a minimum price floor, showing real-time stock counts on every product card, blocking receipts until stock is transferred, printing A4 delivery slips directly from POS, and correcting payment lines on posted orders.

Every feature is opt-in. Enable only what you need via POS Settings so the interface stays clean for your staff.

Features

🔒

Discount Limit + PIN Approval

Set a maximum discount % per order line. A popup requests a manager PIN before any higher discount is accepted.

💲

Minimum Price Guard

Block payment when the effective price after discount drops below a configured floor. PIN override required.

📦

Live Stock Badge

Free-to-sell quantity on every product card. Red = 0, Orange = 1–5, Green > 5.

🚚

Receipt Blocked Until Delivery

Receipt screen and invoice generation locked until the linked stock transfer is validated.

🖨️

Print A4 Delivery Slip

One-click button opens a DOCX/PDF delivery note in a new tab using your configured template.

✏️

Post-Order Payment Editor

Backend wizard lets managers correct payment lines on already-posted orders without cancelling the session.

How It Works

  1. Configure the employee

    Employees → [Employee] → Settings. Enable Discount Approval and set a PIN code.

  2. Set POS limits

    Point of Sale → Configuration → Settings → Order Line Discount. Enable Discount Limit and enter the max %.

  3. Cashier applies a discount

    When the entered discount exceeds the limit, a PIN popup appears automatically.

  4. Manager enters PIN

    If the PIN matches an employee with Discount Approval, the discount is applied and logged. Otherwise a warning is shown.

  5. Receipt & delivery

    After payment, the receipt screen stays accessible only once the delivery is validated. Print the A4 slip with one tap.

Configuration Reference

Employee Form → Settings tab

  • Discount Approval — grant override rights to this employee.
  • PIN Code — 4-digit PIN used in the POS popup.

POS Settings → Order Line Discount

  • Allow Discount Limit — master toggle for the discount ceiling.
  • Max Discount (%) — ceiling cashiers can freely apply.
  • Allow Employees to Override — when disabled, no employee can bypass with PIN.

POS Settings → Minimum Price

  • Enable Minimum Price Guard — blocks payment below the floor.
  • Minimum Price (%) — floor as % of the original sale price.
