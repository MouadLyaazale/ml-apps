🛡️ POS Pro Suite

Discount · Stock · Delivery · Payments

The all-in-one Odoo POS operations toolkit: PIN-protected discount limits, minimum price guard, live stock badges on product cards, receipt blocked until delivery validated, A4 delivery slip printing, and posted-order payment editing.

Point of Sale Odoo 19 OPL-1 Community & Enterprise

Overview

POS Pro Suite tackles the six most common real-world POS pain-points in a single install. Every feature is opt-in — enable only what you need via POS Settings so the interface stays clean for your cashiers and managers.

Features

🔒
Discount Limit + PIN Approval Set a maximum discount % per order line. A popup requests a manager PIN before any higher discount is accepted.
💲
Minimum Price Guard Block payment when the effective price after discount drops below a configured floor. PIN override required.
📦
Live Stock Badge on Product Cards Free-to-sell qty on every card. Red=0, Orange=1-5, Green>5.
🚚
Receipt Blocked Until Delivery Validated Receipt screen and invoice generation locked until the linked stock transfer is fully validated.
🖨
Print A4 Delivery Slip from POS One-click button on the receipt screen opens a DOCX/PDF delivery note using your configured template.
✏
Post-Order Payment Editor Backend wizard lets managers correct payment lines on already-posted orders without cancelling the session.

How It Works

1
Configure the employeeEmployees → [Employee] → Settings. Enable Discount Approval and set a PIN code.
2
Set POS limitsPoint of Sale → Configuration → Settings → Order Line Discount. Enable and set the max %.
3
Cashier applies a discountWhen the entered discount exceeds the limit, a PIN popup appears automatically.
4
Manager enters PINCorrect PIN + Discount Approval = approved and logged. Wrong PIN = warning shown.
5
Receipt & deliveryReceipt accessible only once delivery is validated. Print A4 slip with one tap.

Configuration Reference

Employee Form → Settings tab

  • Discount Approval — grant override rights to this employee.
  • PIN Code — 4-digit PIN used in the POS popup.

POS Settings → Order Line Discount

  • Allow Discount Limit — master toggle for the ceiling feature.
  • Max Discount (%) — ceiling cashiers can apply freely.
  • Allow Employees to Override — when disabled, nobody can bypass.

POS Settings → Minimum Price

  • Enable Minimum Price Guard — blocks payment if price is too low.
  • Minimum Price (%) — floor as % of original sale price.
