How It Works

1️⃣ Before Write — Snapshot
When a sale order is saved with order line changes, the module captures a before-snapshot of all line data.
2️⃣ Write Executes Normally
The standard Odoo write logic runs without any interference — no performance overhead during the actual save.
3️⃣ After Write — Compare & Log
The module compares the after-state with the snapshot, builds an HTML diff message, and posts it as an internal note in the chatter.
